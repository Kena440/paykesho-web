About Security Audit
What does the security audit do?

The security audit automatically scans all database tables for malicious content including:

  • XSS Attacks: Script tags, JavaScript code in text fields
  • SQL Injection: Dangerous SQL patterns and keywords
  • Path Traversal: Directory navigation attempts in file names
  • URL Spam: URLs in address fields (spam/phishing)
  • Invalid Formats: Data that doesn't match required patterns (e.g., NRC format)
When does it run?

The automated scan runs daily at 2:00 AM. You can also run it manually using the button above.

How to handle findings?
  • Delete: Remove the malicious record from the database permanently
  • False Positive: Mark as legitimate data if detection was incorrect

All actions are logged and can be audited.
